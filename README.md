# Wardens of Veylmoor

A third-person 3D fantasy action RPG that runs in the browser and installs on your phone like an app.

**Play:** https://hunter253.github.io/veylmoor/

- Four classes (Bulwark, Ashcaller, Thornstalker, Lumen) with six skills and a talent tree each
- Three regions linked by waystone pillars: Veylmoor, Sunscar Dunes and Frostfang Reach
- Quests, loot with five rarities, mounts, a minimap and the Sunken Abbey dungeon boss

## Install on your phone
Open the play link, then:
- **iPhone:** Safari → Share → **Add to Home Screen**
- **Android:** Chrome → ⋮ → **Install app**

It opens full screen in landscape and works offline after the first visit.
