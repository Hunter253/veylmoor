# Wardens of Veylmoor

A third-person 3D fantasy action RPG that runs in the browser on PC and phone, and installs like an app on both.

**Play:** https://veylmoor.netlify.app

- Five classes (Bulwark, Ashcaller, Thornstalker, Lumen, Reaver) with six skills and a talent tree each
- Five zones linked by waystones: Veylmoor, Sunscar Dunes, Frostfang Reach, Gloamwood and Emberfall Caldera, each with an area boss
- 50 quests, loot with five rarities and five gear tiers, mounts, a minimap and the Sunken Abbey dungeon

## Play on PC
Open the play link in Chrome, Edge or Firefox. Your save stays in that browser, on that PC.

| Action | Control |
| --- | --- |
| Move | W A S D |
| Look | Hold a mouse button and drag |
| Sprint / jump / dodge | Shift / Space / V |
| Attack | Click a monster, or F |
| Skills | 1 to 5 |
| Next target | Tab |
| Talk or use | E |
| Tonic / mount | Q / R |
| Zoom | Mouse wheel |
| Bag / character / quests / spells / map / updates | B / C / L / K / M / U |
| Menu | Esc |

To get a desktop icon and its own window, use the install button in the Chrome or Edge address bar, or Options > Game > Install as an app.

## Install on your phone
Open the play link, then:
- **iPhone:** Safari → Share → **Add to Home Screen**
- **Android:** Chrome → ⋮ → **Install app**

It opens full screen in landscape and works offline after the first visit.
