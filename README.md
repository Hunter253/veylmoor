# Wardens of Veylmoor

A third-person 3D fantasy action RPG that runs in the browser on PC and phone, plays with touch, keyboard and mouse, or a controller, and installs like an app.

**Play:** https://veylmoor.netlify.app

- Five classes (Bulwark, Ashcaller, Thornstalker, Lumen, Reaver) with six skills each, and a talent web per class: a core, six paths of upgrades and bridge strands between them, with notables and keystones that change how spells work
- Levels 1 to 50 across five zones linked by waystones: Veylmoor (1–19), Sunscar Dunes (17–27), Frostfang Reach (25–35), Gloamwood (33–43) and Emberfall Caldera (41–50), each with an area boss, winding roads, rivers, outcrops and landmarks
- The Reaver builds Fury and the Lumen builds Light, spent on skills for up to 50% more damage or healing
- Gems from bosses and elites to fuse and set in sockets
- Day and night, weather, and a moon that runs through its phases every 28 hours, with shadow-filled new moons, moonlit elites at full moon, and Warden markings and relic caches on the quarter moons
- 34 achievements, two of them hidden, some giving a title to show under your name
- Ore, herbs, crystals and wood to gather and beasts to skin for hides, graded by zone from Common to Legendary, for brewing tonics and forging gear at any shop
- Fishing in every zone, with a common, an uncommon and a rare fish in each
- Storage for each hero at every town shop
- 50 quests, drawn gear for each class's weapon types and armor family (plate, leather, cloth) with five rarities and five material tiers, mounts, a minimap and the Sunken Abbey dungeon

## Play on PC
Open the play link in Chrome, Edge or Firefox. You can keep up to five heroes. They stay in that browser, on that PC, and you can export a hero to a file to back it up or move it to another device.

| Action | Control |
| --- | --- |
| Move | W A S D |
| Look | Hold a mouse button and drag |
| Sprint / jump / dodge | Shift / Space / V (Bulwark: hold V to block) |
| Attack | Click a monster, or F |
| Skills | 1 to 5 |
| Next target | Tab |
| Talk or use | E |
| Tonic / mount | Q / R |
| Zoom | Mouse wheel |
| Bag / character / quests / spells / map / updates | B / C / L / K / M / U |
| Menu | Esc |

To get a desktop icon and its own window, use the install button in the Chrome or Edge address bar, or Options > Game > Install as an app.

## Play with a controller
Plug in or pair an Xbox controller (PlayStation controllers work too) and press any button. The game switches to controller prompts on its own.

| Action | Xbox button |
| --- | --- |
| Move / look | Left stick / right stick |
| Sprint | Click the left stick |
| Jump, or talk and use when next to something | A |
| Dodge roll | B (Bulwark: hold B to block) |
| Attack | X |
| Skills 1 to 5 | LB, RB, LT, RT, Y |
| Tonic / mount | D-pad up / D-pad down |
| Next target / minimap | D-pad right (or click the right stick) / D-pad left |
| World map / menu | View / Menu |
| In menus | D-pad moves, A selects, B goes back, LB and RB switch tabs |

To show PlayStation button names instead, go to Options > Controls > Controller buttons.

## Install on your phone
Open the play link, then:
- **iPhone:** Safari → Share → **Add to Home Screen**
- **Android:** Chrome → ⋮ → **Install app**

It opens full screen in landscape and works offline after the first visit.
